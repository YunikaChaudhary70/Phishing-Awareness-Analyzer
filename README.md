# Phishing-Awareness-Analyzer
Phishing Awareness Analysis Tool - DecodeLabs Training

## Objective
Analyze sample emails/messages to identify phishing attempts and explain why they are unsafe.

## Features
- **Red Flag Detection**: Fake domains, Urgent language, OTP/Password requests
- **Link Analysis**: Detects URL shorteners and suspicious links
- **Risk Scoring**: Outputs Low/Medium/High risk level
- **Security Explanation**: Explains "Why Unsafe" for each red flag

## How to Run
```bash
python phishing_analyzer.py
